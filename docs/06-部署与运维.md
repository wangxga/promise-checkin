## 一、部署前置准备清单

### 1.1 域名与备案（关键卡点，耗时最长）
| 步骤 | 说明 | 耗时 |
|---|---|---|
| ① 域名解析 | 在域名服务商把 `api.yourdomain.com` A 记录到服务器公网 IP | 几分钟 |
| ② ICP 备案 | 工信部备案（小程序也强制要求）。通过云服务商（阿里云/腾讯云）的备案系统提交 | **7~20 天** |
| ③ 公安备案 | 备案通过后 30 天内补公安备案（部分省份要求） | 自行把握 |

> ⚠️ **关键**：备案未通过前，国内服务器无法对外提供 web 服务。开发期间可用 `ip:port` 调试，但要尽早启动备案流程。

### 1.2 微信小程序配置
| 步骤 | 说明 |
|---|---|
| ① 注册小程序账号 | [mp.weixin.qq.com](https://mp.weixin.qq.com)，主体可选个人（免费，但不能做支付）或企业 |
| ② 拿 AppID + AppSecret | 后端 `code2Session` 必需 |
| ③ 配置服务器域名 | 小程序后台「开发管理 → 开发设置 → 服务器域名」，添加 `https://api.yourdomain.com` 到 request 合法域名 |
| ④ 配置业务域名（可选） | 如果做 H5 网页版需要 |

### 1.3 服务器环境清单
```
✅ Linux 服务器（推荐 Ubuntu 22.04 LTS 或 CentOS 7+）
✅ 已开放端口：22(SSH)、80(HTTP)、443(HTTPS)
✅ 已安装：Node.js 20 LTS、MySQL 8.0、Redis 7、Nginx、PM2、Git
```

## 二、服务器初始化脚本

### 2.1 一键安装环境（Ubuntu 示例）

```bash
#!/bin/bash
# install-env.sh —— 服务器初始化（仅首次执行一次）

set -e

# 1. 系统更新
apt update && apt upgrade -y

# 2. 安装基础工具
apt install -y curl wget git vim build-essential

# 3. 安装 Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
npm install -g pnpm pm2 npx

# 4. 安装 MySQL 8.0
apt install -y mysql-server
mysql_secure_installation    # 交互式设置 root 密码、清理默认库

# 5. 安装 Redis
apt install -y redis-server
systemctl enable redis-server

# 6. 安装 Nginx
apt install -y nginx
systemctl enable nginx

echo "✅ 环境安装完成"
```

## 三、Nginx 配置（HTTPS 反向代理）

### 3.1 申请免费 SSL 证书（Let's Encrypt）

```bash
# 安装 certbot
apt install -y certbot python3-certbot-nginx

# 自动申请并配置证书（交互式选域名、邮箱）
certbot --nginx -d api.yourdomain.com

# 自动续期（已写入 cron，验证一下）
certbot renew --dry-run
```

### 3.2 Nginx 配置文件

```nginx
# /etc/nginx/sites-available/promise-checkin.conf
server {
    listen 80;
    server_name api.yourdomain.com;
    # 强制跳转 HTTPS
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.yourdomain.com;

    # SSL 证书（certbot 自动注入）
    ssl_certificate     /etc/letsencrypt/live/api.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.yourdomain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 日志
    access_log /var/log/nginx/promise-access.log;
    error_log  /var/log/nginx/promise-error.log;

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3000;   # Node.js 监听端口
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 限流（防恶意刷接口）
    limit_req_zone $binary_remote_addr zone=api:10m rate=20r/s;
    location /api/ {
        limit_req zone=api burst=40 nodelay;
        proxy_pass http://127.0.0.1:3000;
        # ... 同上
    }

    # H5 静态资源（如发布 H5 版本）
    location / {
        root /var/www/promise-checkin-h5;
        try_files $uri $uri/ /index.html;
    }
}
```

```bash
# 启用站点
ln -s /etc/nginx/sites-available/promise-checkin.conf /etc/nginx/sites-enabled/
nginx -t              # 检查配置
systemctl reload nginx
```

## 四、后端部署（PM2 守护进程）

### 4.1 项目部署目录结构
```
/var/www/promise-checkin/
├── current/             ← 当前发布版本（软链接）
│   ├── dist/            ← 编译产物（src/ 编译得到）
│   ├── node_modules/
│   ├── .env             ← 生产环境变量
│   ├── package.json
│   └── ecosystem.config.cjs
└── releases/
    └── 20260622_1030/   ← 按时间戳归档历史版本（便于回滚）
```

### 4.2 PM2 配置文件

```javascript
// ecosystem.config.cjs
module.exports = {
  apps: [{
    name: 'promise-checkin-api',
    script: 'dist/app.js',
    instances: 2,                  // 多进程（按 CPU 数调整）
    exec_mode: 'cluster',
    max_memory_restart: '500M',
    env: {
      NODE_ENV: 'production',
      PORT: 3000
    },
    error_file: '/var/log/promise-checkin/err.log',
    out_file: '/var/log/promise-checkin/out.log',
    log_date_format: 'YYYY-MM-DD HH:mm:ss',
    merge_logs: true,
    autorestart: true,
    max_restarts: 10
  }]
}
```

### 4.3 部署命令

```bash
# 首次启动
cd /var/www/promise-checkin/current
pnpm install --prod
pnpm build              # tsc 编译
pm2 start ecosystem.config.cjs
pm2 save                # 保存进程列表
pm2 startup             # 设置开机自启

# 后续发版（脚本化）
./deploy.sh
```

### 4.4 常用运维命令
```bash
pm2 status                              # 查看进程状态
pm2 logs promise-checkin-api            # 实时日志
pm2 restart promise-checkin-api         # 重启
pm2 reload promise-checkin-api          # 零停机重载（cluster 模式）
pm2 monit                               # 资源监控面板
```

## 六、CI/CD 自动化部署（可选但推荐）

### 6.1 GitHub Actions 示例
```yaml
# .github/workflows/deploy.yml
name: Deploy
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
      - run: pnpm install
      - run: pnpm --filter server build
      - name: Upload to server
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SERVER_SSH_KEY }}
          script: |
            cd /var/www/promise-checkin
            ./deploy.sh
```

### 6.2 服务器端 `deploy.sh`（简易版）
```bash
#!/bin/bash
set -e
APP_DIR=/var/www/promise-checkin
TS=$(date +%Y%m%d_%H%M)

cd $APP_DIR
git pull origin main
pnpm install --prod
pnpm --filter server build

# 归档当前版本
cp -r current releases/$TS

# 重启
pm2 reload promise-checkin-api
echo "✅ Deployed at $TS"
```

## 七、数据库备份

### 7.1 定时自动备份（crontab）
```bash
# 每日凌晨 3:30 备份到本地 + 同步到对象存储（OSS/COS）
30 3 * * * /var/www/promise-checkin/scripts/backup-db.sh
```

```bash
#!/bin/bash
# backup-db.sh
BACKUP_DIR=/data/backups/mysql
TS=$(date +%Y%m%d_%H%M)
mkdir -p $BACKUP_DIR

mysqldump -u promise_app -p'密码' promise_checkin | gzip > $BACKUP_DIR/promise_checkin_$TS.sql.gz

# 仅保留最近 30 天
find $BACKUP_DIR -name "*.sql.gz" -mtime +30 -delete

# 可选：上传到云对象存储（OSS/COS/S3）
# ossutil cp $BACKUP_DIR/promise_checkin_$TS.sql.gz oss://your-bucket/backup/
```

## 八、监控与告警

### 8.1 基础监控
| 监控项 | 工具 | 告警阈值 |
|---|---|---|
| 服务器 CPU/内存/磁盘 | PM2 monit + 系统自带的 `df -h` | 磁盘 > 80% |
| Node 进程状态 | PM2 | 进程挂掉 |
| 接口错误率 | 应用日志统计（pino + 简单脚本） | 5xx > 1% |
| MySQL 慢查询 | MySQL slow_query_log | > 1s |
| HTTPS 证书过期 | certbot + 监控 | 到期前 7 天 |

### 8.2 简易告警脚本（钉钉/企业微信机器人）
```bash
# 检查服务存活，挂了推消息
curl -s https://api.yourdomain.com/api/health || \
  curl -H "Content-Type: application/json" \
       -d '{"msgtype":"text","text":{"content":"❌ 如约打卡 API 挂了！"}}' \
       "https://oapi.dingtalk.com/robot/send?access_token=xxx"
```

crontab 每分钟跑一次。

## 十、应急处理预案

| 故障 | 处置 |
|---|---|
| 服务突然无响应 | `pm2 restart` → 查 `pm2 logs` → 查 nginx error 日志 |
| 数据库连接爆满 | 查 `SHOW PROCESSLIST` 杀慢查询 → 排查连接泄漏 |
| 磁盘写满 | 清理日志 `pm2 flush` + 清旧备份 → 找大文件 `du -sh *` |
| HTTPS 证书过期 | `certbot renew` → `systemctl reload nginx` |
| 误删数据 | 立即从最近备份恢复到新库 → 选择性补回 |
| 被刷接口 | Nginx 限流 + IP 黑名单临时封禁 → 排查是否有漏洞 |
