# 生产部署指南

> 域名：`checkin.itwxg.com` · HTTPS · Node.js + MySQL + Redis

## 一、部署架构

```
微信小程序
  ↓ HTTPS
Nginx（443，TLS 终结 + 限流 + 反代）
  ↓ http://127.0.0.1:3000
Node.js（PM2 守护）
  ↓
MySQL 8 + Redis 7
```

## 二、服务器准备

### 2.1 建库建账号

```bash
mysql -uroot -p <你的root密码>
```

```sql
CREATE DATABASE IF NOT EXISTS promise_checkin DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'promise_checkin'@'localhost' IDENTIFIED BY '生成一个强密码';
GRANT ALL PRIVILEGES ON promise_checkin.* TO 'promise_checkin'@'localhost';
FLUSH PRIVILEGES;
```

### 2.2 Redis 设密码（如对外暴露）

```bash
# /etc/redis/redis.conf
requirepass 你的Redis密码
systemctl restart redis
```

## 三、后端部署

### 3.1 拉代码 + 装依赖

```bash
cd /var/www/promise-checkin
git pull origin main
pnpm install
```

### 3.2 配置环境变量

```bash
cd packages/server

# .env 已有（只含 NODE_ENV）
# 复制生产配置模板，填真实值
cp .env.production .env.production  # 已在仓库里，直接编辑
vim .env.production
```

**必须修改的值**（`.env.production`）：

| 变量 | 说明 |
|---|---|
| `DATABASE_URL` | 改为真实账号密码（localhost） |
| `REDIS_PASSWORD` | Redis 密码 |
| `JWT_SECRET` | `openssl rand -hex 32` 生成 |
| `WX_APPID` | 微信小程序 AppID |
| `WX_SECRET` | 微信小程序 Secret |
| `PORT` | 一般 3000，不用改 |

### 3.3 建表 + 种子数据

```bash
# 生产环境只跑 migration（不跑 seed）
pnpm db:migrate
```

### 3.4 编译 + 启动

```bash
pnpm build
pm2 start ecosystem.config.cjs --env production
pm2 save
pm2 startup  # 开机自启（按提示执行输出的命令）

# 验证
pm2 status
curl http://localhost:3000/health
# → {"code":0,"data":{"status":"ok","deps":{"db":true,"redis":true},...}}
```

### 3.5 确认 dev 后门已关闭

启动日志里**不应**出现 `[dev] 已开启后门`。

## 四、Nginx 配置

### 4.1 申请 SSL 证书

```bash
apt install certbot python3-certbot-nginx
# 先配好 Nginx 的 server_name，再申请证书
cp packages/server/deploy/nginx-checkin.conf /etc/nginx/sites-available/
ln -s /etc/nginx/sites-available/nginx-checkin.conf /etc/nginx/sites-enabled/
# 先注释掉 ssl_certificate 行（还没证书），启动 80 端口
nginx -t && systemctl reload nginx
# 申请证书（certbot 自动改配置）
certbot --nginx -d checkin.itwxg.com
nginx -t && systemctl reload nginx
```

### 4.2 DNS 配置

在你的域名服务商（itwxg.com 管理）加 A 记录：
```
checkin → 你的服务器公网 IP
```

## 五、前端部署

### 5.1 配置生产 API 地址

```bash
cd packages/miniapp
vim env/.env.production
# VITE_SERVER_BASEURL=https://checkin.itwxg.com/api/v1
```

### 5.2 编译

```bash
pnpm build:mp-weixin
# 产物在 dist/build/mp-weixin/
```

### 5.3 上传到微信开发者工具

1. 微信开发者工具打开 `dist/build/mp-weixin`
2. 详情 → 本地设置 → 勾选「不校验合法域名」（开发版）/ 取消勾选（正式版需在后台配域名）
3. 上传 → 填版本号 → 提交审核

### 5.4 微信后台配置服务器域名

mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名 → request 合法域名：
```
https://checkin.itwxg.com
```

## 六、验证清单

- [ ] `https://checkin.itwxg.com/health` 返回 `{"status":"ok"}`
- [ ] dev 后门未开启（启动日志无警告）
- [ ] 小程序能登录（真实微信 code → code2Session → JWT）
- [ ] 打卡功能正常
- [ ] PM2 开机自启（`pm2 startup` 已执行）
- [ ] SSL 证书自动续期（`certbot renew --dry-run` 通过）
